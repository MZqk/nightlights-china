## 交互地图功能

- **任意两年对比**：年份下拉切换，默认 **2021 vs 2025**（全期，与「主要结论」口径一致）
- **波特尔暗夜等级图层**（传播积分版，2021–2025 五年）：第三个模式，把 VIIRS 地表辐亮度经**大气散射传播积分**（半径 300 km 内所有光源按距离幂律衰减叠加）换算为天顶天空亮度，再分级到波特尔 1–9 级。已计远处城市天空辉光，因此城市近郊不再被系统性低估。高反射地表（盐湖/积雪/裸岩）用连片亮区判据标记为灰色存疑。截图：`output/bortle_prop_screenshot.png`
  - **悬停读数已融合**：任何模式下悬停都给出该点 `y1 级 → y2 级` 的等级变化与 `Δlog`，两者互补。实测样例：某点本地辐亮度 2021/2025 均为 0.00 nW（变化图判「低于检测限」），但波特尔等级 3 级 → 4 级，**退化 1 级**——远处城市辉光涨了。截图：`output/hover_readout_screenshot.png`
  - **1 级不可达**：自然本底 0.25 mcd/m² 对应 21.60 mag，低于 1 级阈值 21.7 mag，中国境内几乎没有真正的 1 级天空。
  - **五年等级转移矩阵**（限中国境内，867,260 个 120″ 像元）：光害加重（等级升高）**7.69%**、等级不变 91.33%、减轻 0.98%，**净加重 +58,178 像元**。最大一股流是 **2 级→3 级 24,053 像元**（暗夜区被侵蚀），反向 3 级→2 级仅 3,262，约 1 : 7.4。
  - **查表法对照**（`scripts/bortle.py`，已降级为对照）：只看本地像元、不计远处辉光，且把 0 nW 一律判 1 级（占全图 89%），偏乐观。同一份 2025 数据两者差距显著：淀山湖 5 级 vs **8 级**（差 3 级）、密云 8 vs 6、阿里狮泉河 6 vs 4。
  - ⚠️ **历史坑（勿回退）**：`bortle_prop.py` 的分级曾因 `BORT_BINS` 正向遍历被逐次覆盖，导致全图 99.96% 判成 9 级且**不报错**。必须 `for thr, l in reversed(BORT_BINS)`。
- **四种模式**：变化图（对数比值 / 绝对差）· 亮度图（单年年度合成）· 波特尔（等级）· **双变量**（等级 × 变化）
- **双变量着色**（等级做底色 + 变化做冷暖）：色相编码该年波特尔等级（深蓝 1 级 → 暖白 9 级），冷暖明暗编码 2021→2025 变化（变亮 → 更亮更艳偏暖，变暗 → 更暗更灰偏冷）。等级 10 档 × 变化 33 档预计算成扁平 `Uint8Array`，逐像素 O(1) 查表——289 万像素现算 HSV 转换不可行。低于检测限的像元没有可信 Δlog，按「不变」处理、显示为纯等级色（「这里很暗且无可测变化」本身是信息）。图例是 9×5 的二维矩阵。截图：`output/bivariate_screenshot.png`
  - 已知局限：1–3 级基准色本身接近黑，暗端的冷暖差异会被压缩，等级越高对比越明显。
- **可调信号下限**：0.5–6.0 nW·cm⁻²·sr⁻¹（默认 1.5，用于滤除暗区伪信号）
- **缩放平移**：滚轮 + 拖拽 + 双击复位；悬停显示经纬度、两年辐亮度、Δlog 与倍数
- **两级行政区**：省级 / **县市区**（2875 单元）切换。县级**只做「查询单元」，不做 choropleth 填色**——底图保留完整的 120″ 变化栅格，县界默认不画，鼠标悬停到某县时才描出它的轮廓，并在读数里给出县名、总亮度比、Δlog、有效像元、连片亮区规模与置信档；点排行行可飞行定位。**为何弃用填色**：逐县单色填充会把连片同值的县糊成一个大色块（珠三角各县 Δlog 同档 → 整片一色，看起来像同一个县），掩盖掉栅格本身的细节
- **县界显示**（县级视图）：隐藏 / **悬停**（默认）/ 全部三态。置信档（高 66 / 中 / 低）不再影响地图显示——它原本只控制填色范围，填色取消后改由悬停读数与排行表行首圆点承载；排行恒排除低置信单元
- **样本分档排行**：县级排行先按 30″ 有效像元数分 A（≥1000）/ B（500–999）/ C（200–499）三档，档内按总亮度比降序、各档前 10——避免 2875 次抽样挑极值的选择性偏差；样本档 ≠ 置信档（行首圆点标注置信）
- **县级「等级」列 + 暗夜筛选**：排行表在县名前加一列波特尔等级（该县在 120″ 等级图层上覆盖像元的**中位数**），`↑`/`↓` 表示 2021→2025 等级升高/降低，`—` = 网格下样本不足 3 个像元（多为面积过小的中心城区）。配套筛选「全部 / ≤5 级 / ≤4 级」，用来找「还够暗、且正在变亮」的候选县。**实测：2021→2025 的 505 个达标单元里，≤4 级只剩 7 个**（昌吉市 4 级 ×1.34、九台区 ×1.17、米东区 ×0.97、呼兰区 ×1.25、绥中县 ×1.19 等），且样本 A 档（≥1000 有效像元）为 **0**——中国境内「够暗又够大」的县几乎没有。截图：`output/rank_bortle_screenshot.png`
- **排行方向**：增亮（增幅降序）/ 变暗（降幅升序，只纳入总亮度比 < 1 的净减少单元）。省级 2021→2025 仅香港（×0.96）与贵州（×0.99）净减少——近乎普遍变亮本身就是结论
- **省级排行**：按全省灯光总亮度比排序，实时联动所选年份对
- **范围/标注开关**：仅中国境内、省名与城市标注、省界透明度、γ 曲线
- **可分享链接**：`#y1=2021&y2=2025&mode=abs&unit=raw&sig=1.5`
  `mode` 取值 `diff`（变化图）/ `abs`（亮度图）/ `bortle`（波特尔）/ `bi`（双变量）；另有 `lv=district`（县级视图）、`bndm=hide|hover|all`（县界显示）、`rd=down`（变暗榜）、`bmax=5|4`（暗夜筛选）。例：`#mode=bi&lv=district&bndm=all&bmax=4&z=6&cx=120.6&cy=31.3`。
  旧参数 `conf=high|mid|all` 与 `low=1` 仍兼容：`conf=all` 映射为 `bndm=all`，其余按默认「悬停」处理

### 双分辨率口径（容易误读）

县级填色与排行在 **30″（≈925 m）** 网格统计；浏览器底图与光标逐点读数是 **120″**——原始 30″ 栅格经 FACTOR=4 块平均降采样（7560×6120 → 1890×1530），否则五年解码需近 1 GB 内存。两者是同源数据的不同空间聚合层级：光标读数是单个 120″ 像元值，县级数值是该单元全部 30″ 有效像元的总和之比，**不应逐值对照**。

## 指标定义

```
Δ = log₁₀( (L₂ + ε) / (L₁ + ε) )      ε = 0.1 nW·cm⁻²·sr⁻¹
有效像元：max(L₁, L₂) ≥ MIN_SIG（默认 1.5 nW·cm⁻²·sr⁻¹）
```

Δ = +0.30 表示亮度增至 2 倍，−0.30 表示降至 1/2。用对数比值的理由：夜光跨 3 个数量级，绝对差会被少数极亮城市完全主导，乡村变化不可见。

## 主要结论

全国总量（同源可比）逐年上升。下表采用 **MIN_SIG = 1.5 nW·cm⁻²·sr⁻¹** 口径，
与地图、省级、县级统计完全一致：

| 区间 | 总辐亮度变化 | 亮区面积变化（有效像元） |
|---|---|---|
| 2021→2022 | +4.34% | +6.45% |
| 2022→2023 | +5.95% | +7.42% |
| 2023→2024 | +5.13% | +6.70% |
| 2024→2025 | **+4.80%** | **+1.40%** |

全期总亮度 11.58 → 14.11（×10⁶），累计 **+21.8%**；亮区面积 138.9 万 → 171.8 万像元（+23.7%）。

**最后一年值得单独说**：亮区面积只增 1.40%（是前三年 +6.45% / +7.42% / +6.70% 的零头），
总亮度却仍增 4.80%——**新增亮区的速度骤降，而既有亮区仍在变亮**。

> **别读成"转向加密"**。县级数据不支持这个推论：2875 个单元里 **78.1% 的县亮区面积仍在扩大**，
> 只有 14.4%（414 个）面积缩小，而这 414 个里仅 17.9%（74 个）是"面积缩小但总亮度上升"的加密型，
> 且多为小样本县（塔什库尔干 33→31 px、镶黄旗 12→11 px）。
> 全国层面的正确表述是**扩张放缓**：铺开的速度慢下来了，但远没有停。

> **已作废的旧结论**：本表早期版本使用 `>0 nW` 口径，写作「2025 年总量微增 2.0%、
> 有效像元减少 7.3%，边缘暗区在灭灯」。该说法不成立——那些消失的像元
> **99.91% 亮度 <1.5 nW、中位 0.252 nW**，散成 21.7 万个碎块，对总亮度贡献仅 0.87%，
> 是年度合成产品在暗区的检测限噪声，不是熄灯；在 ≥1.5 口径下有效像元实为 **+1.40%**（方向相反）。
> 两种口径的完整对照见 `output/calibration_report.md` 第 1、3 节。
> 省级与县级排行不受影响（本就用 ≥1.5 口径）。

**口径说明**：下表用「全省灯光总亮度比」（`sum_ratio`，即该省有效像元辐亮度总和之比），
不用 `10^Δlog`——后者是「典型像元倍数」，西藏为 ×2.29 而全省总量仅 ×1.58，两者混淆会造成严重夸大。

## 局限与不可采信项（重要）

1. **这不是「光污染」地图。** VIIRS 测的是地表向上辐亮度，不是天顶天空亮度（mag/arcsec²）。二者需经大气散射传播模型换算，本图未做。严格名称是「夜间灯光辐亮度变化图」。
2. **高反射伪信号（已核查确认）。** 两条独立判据：
   - **绝对水平不合理**：五年平均辐亮度——青海格尔木 **84**、西藏阿里 **61**，而上海核心 94、杭州核心 **76**、拉萨市区 62。
     一个荒漠盐湖区高于杭州市中心，数值本身说不通。
   - **空间形态不像城市**：亮像元（>20 nW）中孤立散点占比，西藏 **13.2%** vs 浙江 **4.9%**（2.7 倍）；
     最大连片团块西藏 **116** 个像元 vs 浙江 **1,377** 个（约 1/12）。

   成因是积雪 / 盐湖 / 裸岩把月光反射回卫星——VIIRS 测的是地表向上辐亮度，无法区分人工光源与高反射地表。
   据此 **西藏的总亮度比 ×1.58 不能直接采信**；内蒙古、黑龙江、青海同样可能被污染。
   相对可信的是东部省份（浙江 ×1.25、江西 ×1.25），亮像元形态连片、孤立率低。
   > 注：判定过程修正过一次。最初设想用「逐年是否单调增长」判别，实测否决——
   > **城市核心像元逐年同样波动**（杭州 79.7→72.2→78.5→73.8→74.4，深圳持续下降）。
   > 原因是核心区已饱和，真正增亮发生在城市边缘。该判据已废弃。
3. **小基数效应。** 亮度接近检测限的像元，年度微小波动即产生数倍「对数变化」。默认 1.5 nW 下限已抑制大部分，调低下限可复现该现象。
4. **LED 换灯假性变暗。** VIIRS DNB 蓝波段灵敏度低，高压钠灯→白光 LED 改造会使卫星读数下降，而人眼感知与生态影响未必降低。这是近年「欧洲灯光变暗」结论的主要争议点。
5. **过境时刻固定**（约地方时 01:30），午夜后熄灯行为与居民前半夜实际感受不同步。
6. **云量/气溶胶年际波动**会影响年度合成的有效观测数，进而引入非真实变化。
7. **混合源方案已被否决。** 曾评估用 OpenLandMap/EOG VNL（2012–2024，60–84 MB/年）承担历史年份以省带宽，交叉验证结果否决了该方案：两产品比值中位 9.89 但四分位跨度 [8.26, 12.20]、5–95% 跨度 [6.04, 17.15]，比值随亮度区间变化，线性定标无法消除；有效像元数相差 15–20%。最终全程改用 Black Marble 同源数据。
8. **2025 年部分省份的年度变化幅度接近噪声量级。** 分省数据质量诊断（`scripts/diag_dataquality.py`，
   结果见 `output/data_quality.csv`，136 行 = 34 省 × 4 个相邻年对）实测：

   - 2024→2025 全国「极暗像元（0 < L < 1.5 nW）消失率」中位 10.80%、最大 31.98%（西藏）、最小 0.00%（澳门），
     但 **24 / 34 个省与自身对照年基线持平**；
   - 10 个省相对基线升高 ≥5 个百分点（广西、湖北、湖南、辽宁、江西、贵州、广东、福建、四川、重庆），
     分散在全国而非集中于某一地理区域，因此不像单一天气事件造成的区域性数据问题；
   - 这 10 个省中 **7 个 2024→2025 总亮度比 < 1.03**——广西 ×1.005、贵州 ×1.013、重庆 ×1.018、
     湖南 ×1.020、辽宁 ×1.021、四川 ×1.025、湖北 ×1.027——**当年变化在噪声量级，
     不宜单独解读为「变暗」或「变亮」**；其余 3 个（广东 ×1.059、福建 ×1.064、江西 ×1.045）明确增长，不受影响；
   - 西藏、新疆、青海的极暗像元消失率绝对值偏高（16–32%），但与其自身对照年一致
     （西藏 32.90% → 31.98%，新疆 18.58% → 16.72%），属西部暗区常年特性，**不是 2025 年特有的问题**。

   > 判读方法上纠正过一次：不能只看「亮区像元数减少」就判趋势存疑——
   > 退出的多是边缘暗区，省级总亮度可能仍在增长，必须联合 `sum_ratio` 一起看。

## 县级（县市区）口径

省级结论不能下推到县级。30″ 网格在县尺度上会同时撞到**样本量**与**伪信号**两堵墙。

### 边界

阿里云 DataV.GeoAtlas 递归抓取（34 省 → 363 地级 → 县级），得 **2875 个单元**，耗时 9 s。
- 34 个「直筒子市」（东莞、中山、儋州、嘉峪关、济源、仙桃、兵团市等）与台湾省无县级下级，
  其市级接口返回 404，回退为地级／省级整体作 1 个单元 → 故总数 2875 而非 2843。
- 九段线 feature 的 adcode 是字符串 `100000_JD`，需按字符串排除。
- 简化 tol=0.005°（≈500 m）+ 坐标量化 ×1e4 + delta/zigzag-varint 编码，27 万点 → **base64 1.25 MB**
  （优于 gzip 方案的 1.97 MB，且不依赖 `DecompressionStream`，Safari <16.4 / Firefox <113 也能跑）。

### 统计性能

`zonal.py` 的「逐多边形开窗」在 2875 单元下会慢 1–2 个数量级。`zonal_district.py` 改为
**rasterize 一次性标签栅格 + `np.bincount` 向量化**：rasterize 2 s / 读年 0.5 s / 每对 bincount 0.2 s，
含逐年连片分析共 **26 s** 跑完全部 10 个年份对。

### 三重置信门限（核心）

| 档 | 有效像元 | 末年有效像元均值 | 所属最大连片亮区 |
|---|---|---|---|
| 高 | ≥1000 | ≥5 nW | ≥2000 px |
| 中 | ≥200 | ≥3 nW | ≥500 px |
| 低 | 其余 → 地图灰显、不进排行 | | |

| 肇源县 | 黑龙江 | 574 | **×36.66** | 27.2 nW | **176 px** | 大庆油田火炬 |
| 杜尔伯特蒙古族自治县 | 黑龙江 | 259 | ×9.57 | 12.4 | 29 px | 同上 |

|---|---|---|---|

2000 / 500 px 这两个连片阈值此前未标定。用 `district_stats.csv` 做敏感性分析
（2021→2025，A 档 = 有效像元 ≥1000 且不低置信）：

## 两级口径数值互校

`zonal.py`（省级）与 `zonal_district.py`（县级）是两段独立代码，原先只靠"口径注释相同"保证一致。
`scripts/xcheck_levels.py` 在**同一份年对 mask** 下重算三层并逐格对比（7 s，340 行结果见
`output/level_xcheck.csv`）：

| 层 | 含义 | 来源 |
|---|---|---|
| A | 已发布省级产物 | `zonal.py`，`geometry_mask` 逐省开窗 |
| B | 省级重算 | rasterize 省界 + `bincount` |
| C | 县级聚合到省 | rasterize 2875 县界 + 按省归并 + `bincount` |

**不能直接拿两个 CSV 相减**：县级 `sum_base`/`sum_cmp` 是**单年** mask（`L ≥ MIN_SIG`）下的总量，
省级 `sum_ratio` 是**年对** mask（`max(L₁,L₂) ≥ MIN_SIG`）下的总量，像元集合不同，相减毫无意义。

A↔B 检验方法差异（`geometry_mask` vs `rasterize`，同为像元中心归属规则），B↔C 检验边界几何差异
（34 省界 vs 2875 县界的并集）：

| 对比 | 指标 | 中位偏差 | 最大偏差 | 判读 |
|---|---|---|---|---|
| A↔B | 有效像元 | 0.000% | 0.091% | 方法等价 ✓ |
| A↔B | 总亮度比 | 0.000% | 0.010% | 方法等价 ✓ |
| A↔B | 平均 Δlog | 0.00000 | 0.00010 dex | 方法等价 ✓ |
| B↔C | 有效像元 | 0.040% | **21.43%（澳门）** | 见下 |
| B↔C | 总亮度比 | 0.010% | 1.31%（澳门） | 见下 |
| B↔C | 平均 Δlog | 0.00010 | 0.00990 dex（澳门） | 见下 |

**结论**：两级统计在方法层面完全等价（A↔B 偏差 < 0.1%）。B↔C 的偏差仅集中在澳门与香港，
其余 32 个省级单元全部 ≤ 0.38%：

| 单元 | 省级 A/B | 县级聚合 C | 成因 |
|---|---|---|---|
| 澳门特别行政区 | 56 px | 68 px（+21.4%） | 省级为单一多边形；县级拆为 8 个堂区（花地玛 9 / 花王堂 1 / 望德堂 1 / 大堂 14 / 风顺堂 2 / 嘉模堂 17 / 路凼填海 9 / 圣方济各 15），并集含填海区边界，在 30″ 网格下多出 12 个像元。8 个堂区全部 `low` 置信、不进排行，对结论无影响 |
| 香港特别行政区 | 1,341 px | 1,355 px（+1.04%） | 同理，县级拆为 18 区 |
| 其余 32 省 | — | ≤0.38%（中位 0.04%） | 海岸线与飞地的栅格归属差 |

340 条记录中偏差 >0.4% 的共 20 条，**全部**属于澳门与香港（各 10 个年对），其余 320 条无一条超过 0.4%。

全局几何差：省界内有 7,613 个像元无县级标签，县级标签有 6,092 个落在省界外（总 1,390 万像元的 0.05%）。

## 复现

⚠️ **本仓库不包含大数据**：`data/proc/*.tif`（约 100 MB）、`data/raw/districts_full.json`（约 25 MB）、
`data/raw/districts_web.json`、`output/assets.json` 都可从公开数据源重建，故未纳入版本库（见 `.gitignore`）。
因此 **clone 之后不能直接跑 `build_html.py`**，必须先补齐数据。

只想看地图则无需重建：直接打开 `output/中国夜间灯光变化地图.html`（单文件、零外部依赖、可离线）。

```bash
git clone https://github.com/MZqk/nightlights-china.git
cd nightlights-china
python3 -m venv .venv && source .venv/bin/activate
PY=python3                      # 或你自己的解释器路径

# 0. 依赖（scripts/download.py 只用标准库，其余脚本需要下面这些）
$PY -m pip install -r requirements.txt

# 1. 下载（16 段并行 + 断点续传；单包 650–930 MB，解压后自动删除 zip）
$PY scripts/download.py 2021 2022 2023 2024 2025 --parts 16
# 2. 预处理：裁 bbox + 30″ 重采样 + 负值截断（输入名与上一步输出一致）
for y in 2021 2022 2023 2024 2025; do
  $PY scripts/prep.py "[{\"src\":\"data/raw/viirs_${y}_raw.tif\",\"year\":${y}}]"
done
# 3. 打包为前端资产（16bit 拆 R/G 通道 PNG，1.6 MB/5 年）
$PY scripts/pack.py
# 4. 省级分区统计
$PY scripts/zonal.py
# 5. 县级边界：抓取 → 简化编码（~400 次请求，9 s）
$PY scripts/fetch_districts.py
$PY scripts/simplify.py
# 6. 县级分区统计（26 s）
$PY scripts/zonal_district.py
# 6b. 波特尔暗夜等级：传播积分，五年各一份（每年约 1.3 s，跑完自动打印等级转移矩阵）
$PY scripts/bortle_prop.py 2021 2022 2023 2024 2025
# 6c. 县级波特尔等级中位数（供排行表「等级」列与暗夜筛选）
$PY scripts/zonal_bortle.py
# 6d. 查表法对照版（可选；前端已不采用，仅供口径对比）
$PY scripts/bortle.py
# 7. 生成单文件 HTML
$PY scripts/build_html.py
# 8. 两级口径数值互校（可选，7 s；改过 zonal / zonal_district 后必跑）
$PY scripts/xcheck_levels.py
# 8b. 分省数据质量诊断（可选，3 s）
$PY scripts/diag_dataquality.py
# 9. 数据源交叉验证（可选，需另外下载 EOG VNL 参考年）
$PY scripts/xcheck.py
```

磁盘占用峰值约 3 GB（全球包下载→裁剪→立即删除）。全流程计算约 2 分钟（最重的几步：
县级统计 26 s、两级互校 7 s、波特尔传播积分五年合计约 7 s，其余各步秒级），耗时几乎全在网络：源站单连接约 0.05 MiB/s，
并行加速比实测线性（8 段 0.44 MiB/s ≈ 8.2×），
16 段外推 ≈0.9 MiB/s，即单年 928 MB 约 18 分钟、五年 1.5 小时量级（首次下载时约为 45 分钟）。
