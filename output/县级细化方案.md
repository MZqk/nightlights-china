# 县市区级精细化方案（数值均为本机实测，非估算）

## 结论

三层改造：**边界数据 → 分区统计 → 前端图层**。

核心判断：**县级信息的主载体必须是矢量 choropleth（每县一个统计值），不能靠栅格放大。**
原因：栅格做到全分辨率（925 m）在浏览器端需 5 层 × 7560×6120 × 4 字节 ≈ **928 MB** 内存，不可行；
而 2875 个县的填色只需 2875 个数字，且与缩放无关，永远锐利。

## 三个必踩的坑（县级才会暴露，省级被平均掉了）

### 1. 样本不足 — 59% 的县不够格

有效像元中位数仅 145（≈124 km² 亮区）。市中心区更极端：澳门望德堂区 **1 像元**、天津和平区 **13 像元**。
这些单元的「变化倍数」纯属噪声。**必须设门限 + 灰显，否则地图一半区域是假的。**

### 2. 伪信号与非城市光源被放大（实测已证实）

2021→2025 总亮度比 Top（仅列有效像元 ≥200 者）：

| 县 | 省 | 有效像元 | 总亮度比 | 2025 平均亮度 |
|---|---|---|---|---|
| 肇源县 | 黑龙江 | 574 | ×36.66 | 2.4 nW |
| 杜尔伯特蒙古族自治县 | 黑龙江 | 259 | ×9.57 | 0.4 |
| 勐腊县 | 云南 | 288 | ×4.14 | 0.4 |
| 江陵县 | 湖北 | 202 | ×3.42 | 1.5 |
| 奇台县 | 新疆 | 581 | ×2.70 | 0.2 |
| 巴里坤哈萨克自治县 | 新疆 | 228 | ×2.48 | **0.0** |

肇源、杜尔伯特同属大庆油田辖区 —— 这是**油气田火炬**，不是城市照明；奇台、巴里坤 2025 平均亮度 0.0–0.2 nW，
是**近检测限 + 高反射地表**伪信号（README 已证实该类机制）。
被门限剔除的样本里还有 西沙区 ×inf（0 像元）、阿拉善右旗 ×8.04（62 像元）。

**县级 Top-N 排行若不设双重门限，榜首 100% 是伪信号。**

### 3. 排行选择性偏差

2875 个单元取 Top-N，等价于从 2875 次抽样中挑最大值，必然选中极端样本。
必须**先按样本量分档，档内再排序**，并在 UI 明示档位。

## 实施方案

### 1. 边界（已就绪，待简化）

```
scripts/fetch_districts.py  →  data/raw/districts_full.json (2875, 23.9 MB)
scripts/simplify.py         →  data/raw/districts_web.json
   shapely.simplify(tol=0.005, preserve_topology=True)
   × 坐标 ×1e4 取整 + 去连续重复点
   + 每县 bbox 索引（视口裁剪 / 命中测试）
   + gzip + base64 内嵌，浏览器用 DecompressionStream('gzip') 解压
```

### 2. 统计（替换 zonal.py 的逐多边形开窗）

```
scripts/zonal_district.py
   rasterio.features.rasterize → 一次性 7560×6120 uint16 标签栅格 (1.2 s)
   逐年 read → np.bincount(label[mask], weights=...) 向量化
   输出 output/district_stats.csv (2875 × 10 年对) + output/district_web.json (前端精简)
```

### 3. 前端（`build_html.py` 新增县级模式）

- **县级 choropleth 填色**：按所选年对与指标给县面上色，分辨率无关
- **LOD**：缩放低于阈值只画省界；进入县级视图才绘制县界，按 bbox 做视口裁剪
- **交互**：hover/点击显示 县名 / 有效像元 / sum_ratio / Δlog / 逐年亮度 / 置信档
- **置信度灰显**：样本不足或近检测限的县填灰 + 斜纹，不参与排行
- **排行面板**：按样本量分档（≥1000 / ≥500 / ≥200），档内排序
- 栅格保持 FACTOR=4（或升到 2，+3 MB），**不作为县级主视觉**

### 4. 门限建议

| 规则 | 值 |
|---|---|
| 进排行 / 参与填色 | 有效像元 ≥ 200（≈170 km² 亮区） |
| 近检测限判据 | 末年有效像元中位数 < 3 nW → 标"不可采信" |
| 置信三档 | 高（≥1000 px 且中位数 ≥5 nW）／中（≥200）／低（其余，灰显） |

### 5. README 新增「县级口径」章节

必须写明：油气田火炬、盐湖/积雪高反射、撤县设区导致 2021–2025 边界口径不一致（DataV 为近年快照）、小样本门限。

## 选项

- **A 全套执行**：简化 + 县级统计 + HTML 县级 choropleth 模式（HTML 约 4–5 MB）。推荐。
- **B 只做数据层**：`simplify.py` + `zonal_district.py` + CSV，前端不动。半天内出数，可先用 CSV 做分析。
- **C 只做视觉层**：边界简化 + choropleth 上色，沿用省级统计口径下钻（不重算县级指标，精度不达标，不推荐）。

# 实施结果（方案 A，已完成）

## 新增文件

| 文件 | 说明 |
|---|---|
| `scripts/fetch_districts.py` | DataV 递归抓取 → `data/raw/districts_full.json`（2875 单元 / 23.9 MB / 9.2 s） |
| `scripts/simplify.py` | tol=0.005 简化 + delta/zigzag-varint 编码 → `data/raw/districts_web.json`（base64 1.25 MB） |
| `scripts/zonal_district.py` | rasterize + bincount 统计 → `output/district_stats.csv`（28,750 行）+ `district_stats.json`（1.14 MB） |
| `output/中国夜间灯光变化地图.html` | 4.68 MB，新增县市区层级 |

编码方案改判：**放弃 gzip + DecompressionStream**（Safari <16.4 / Firefox <113 缺失该 API），
改自研 delta+zigzag varint：**0.94 MB 二进制 / 1.25 MB base64**，优于 gzip 的 1.97 MB，且零 API 依赖。

## 与原方案的偏差（重要）

原方案的三重门限第二道是「末年有效像元均值 ≥3 nW」。**实测不成立**：
肇源县末年有效像元均值 **27.2 nW**（不是我先前按全县像元算的 2.4）——因为有效像元本身就是火炬，
均值必然高。该门限完全拦不住伪信号。

追加第三道门限「**所属最大连片亮区规模**」（8 邻域连通，阈值 5 nW）：

| 单元 | 连片亮区 | 判定 |
|---|---|---|
| 肇源县（大庆油田火炬） | 176 px | 低置信 ✓剔除 |
| 奇台县 / 巴里坤（高反射） | 51 / 19 px | 低置信 ✓剔除 |
| 义乌市 | 2,036 px | 保留 |
| 昆山市（长三角连片） | 42,418 px | 保留 |

**另一条被否决的判据**：孤立点率。省级有效（西藏 13.2% vs 浙江 4.9%），县级失效——肇源县孤立点率 **0.0%**。

## 剔除效果（2021→2025）

| | 榜首 | 总亮度比 |
|---|---|---|
| 三重门限前 | 黑龙江肇源县 | ×36.66 |
| 三重门限后 | 河南尉氏县 | ×2.80 |

之后为 济阳区 ×2.25、西华县 ×1.96，以及雄安（安新县 ×1.87、雄县 ×1.67）——与实地建设事实吻合。
达标 505 / 2875 单元（66 高 / 439 中），覆盖全国 **44.6%** 的有效像元。
